PROJECT OVERVIEW
This project analyzes Rossmann Store Sales data and builds a machine learning model for demand forecasting. The analysis covers store performance, promotions, seasonality, competition distance, and forecasting performance.

FORECASTING MODEL
Model:
- Random Forest Regressor

Model parameters:
- max_depth = 15
- n_estimators = 20
- random_state = 42
- n_jobs = -1

Chronological train-test split:
- Training data: before 2015-06-01
- Test data: 2015-06-01 onward

MODEL PERFORMANCE
- MAE: approximately ₹451.00
- RMSE: approximately ₹688.30
- R²: approximately 0.9672

Interpretation:
The model achieved a high R² on the held-out test period and produced an average absolute error of approximately ₹451.

FORECAST ACCURACY DASHBOARD METRIC
The Power BI dashboard uses a business-defined metric:

Forecast Accuracy % =
1 - (Sum of Absolute Error / Sum of Actual Sales)

Dashboard result:
- Forecast Accuracy: 92.69%

Important:
This is a business-defined forecasting metric. It is not classification accuracy.
